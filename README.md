# 🍕 Origine | Pizza Napoletana & Fermentação Lenta

> **Modelo conceitual e responsivo de Landing Page de alta gastronomia, desenvolvido para portfólio profissional de desenvolvimento Web.**

---

## 📌 Sobre o Projeto

Este projeto é uma **Landing Page completa e autoral** criada para simular a presença digital de uma pizzaria artesanal contemporânea focada no método tradicional napolitano e fermentação natural prolongada (72 horas).

O design foi concebido com uma paleta de cores sofisticada (tons terracota, dourado suave, grafite escuro e creme), tipografia editorial clássica (*Playfair Display* e *Plus Jakarta Sans*) e elementos visuais limpos, valorizando a identidade visual do negócio gastronômico.

> [!NOTE]
> Este projeto foi desenvolvido como **modelo genérico para portfólio**, podendo ser adaptado para restaurantes, pizzarias, bistrôs, confeitarias ou qualquer negócio de gastronomia artesanal.

---

## ✨ Funcionalidades e Seções

- **Hero Header de Alto Impacto:** Apresentação da marca com slogan autoral, proposta de valor e chamadas para ação (CTA).
- **O Método & Estatísticas:** Seção explicativa sobre a técnica de fermentação em baixa temperatura, trigo tipo 00 e forno a lenha em 450 °C.
- **Origem dos Ingredientes:** Cards ilustrativos detalhando ingredientes nobres (*Pomodoro San Marzano*, *Fior di Latte*, *Azeite Extravirgem*).
- **Cardápio Interativo (Menu Autoral):**
  - Grid de produtos com fotos em alta definição, preços e descrições detalhadas.
  - Destaque especial de *Assinatura do Chef* na pizza de trufas negras.
  - Links com mensagens personalizadas pré-formatadas para pedidos via WhatsApp.
- **Canal de Pedidos & Concierge Digital:** Área destacada para pedidos rápidos com informações de endereço físico e horário de funcionamento.
- **Botão Flutuante de WhatsApp:** Acesso rápido ao canal de contato fixado no canto inferior direito da tela.
- **Design 100% Responsivo:** Adaptação fluida para smartphones, tablets e desktops (Mobile-First CSS).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico:** Estruturação otimizada para SEO, acessibilidade e navegadores modernos (`<header>`, `<nav>`, `<section>`, `<footer>`).
- **CSS3 Moderno:**
  - CSS Custom Properties (Variáveis CSS para temas, fontes e paleta de cores).
  - Flexbox e CSS Grid para layouts complexos e responsivos.
  - Efeitos de transição suaves, sombras sutis e tipografia fluida.
- **Google Fonts:** Tipografias *Playfair Display* (serifada) e *Plus Jakarta Sans* (sans-serif geométrica).
- **Ícones Vetoriais (SVG):** Ícones inline leves e nítidos em qualquer resolução de tela.

## 🚀 Como Executar Localmente

1. Clone este repositório:
   ```bash
   git clone https://github.com/anajufirmiano/pizzaria.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd pizzaria
   ```
3. Abra o arquivo `index.html` em seu navegador de preferência:
   - Dê um duplo clique no arquivo `index.html`; ou
   - Use uma extensão como o **Live Server** no VS Code.

---

## 🎨 Como Personalizar para o seu Negócio

1. **Número do WhatsApp:**
   - No arquivo `index.html`, localize as tags com `https://wa.me/55...` e substitua pelo número do seu estabelecimento com DDD.
2. **Itens e Preços:**
   - Edite a seção `#cardapio` para alterar nomes, descrições, fotos e valores das pizzas.
3. **Cores e Identidade:**
   - No arquivo `style.css`, edite as variáveis no bloco `:root` para trocar a paleta de cores primária, secundária e fundos.
